C 盘清理工具  v1.1（本机定制版）
================================

改编自 spt11cn/CleanCDrive v1.0。
在原版 8 个模块基础上，针对这台电脑（Redmi Book 14 / Windows 11）的实际情况
新增了两个小米组件模块 —— 这台机器上版本堆积最严重的就是小米全家桶。

另外修掉一个原版问题：WinSxS 模块原本会递归统计目录大小，几十万个硬链接会让
整个扫描卡住好几分钟。现在跳过统计，扫描可以秒过。


一、怎么运行
------------
最省事：双击 CleanCDrive.exe（11 MB 单文件，不用装 Python，不写注册表）。

  · 首次启动会先解压到临时目录，约 1~2 秒才能看到窗口，属正常现象。
  · 杀软偶尔会把 PyInstaller 打包的程序误报，加白名单即可。
  · 想清 Program Files / Windows 下的项目（小米组件、Edge、夸克、WinSxS、更新缓存）
    必须有管理员权限。普通权限下这些模块会显示「需管理员」且不能勾选，
    点界面顶部黄色提示条上的「以管理员身份重启」，或直接右键 exe 选「以管理员运行」。

也可以用源码跑（需要 Python 3.8+ 且带 tkinter）：

  双击「启动 C盘清理工具.cmd」——启动器会自己找一个能用的 Python，
  并且对每个候选实际试一次 import tkinter（有些发行版不带 tkinter，
  直接调 pythonw 会静默失败、什么都不弹），找不到会提示去官网下载。

本机已经装好 Python 3.12.10（winget 装的，带 tkinter 8.6），两种方式都能用。


二、它会做什么
--------------
窗口里列出 10 个清理项，每一项先扫描出实际占用，再让你勾选。
打开程序时不会自动扫描，尺寸都显示「—」，点「扫描体检」（或按 F5）才开始。

  小米管家 MiService 旧版本   ★新增  管家升级遗留的版本目录（保留服务在跑的）
  小米组件其他残留           ★新增  AI 服务旧版本 / 旧版管家 / 云更新器安装包
  Windows 更新缓存                 已装完的更新包残留
  系统临时文件                     Windows\Temp 内超 2 小时的文件
  升级/回滚残留                    $WinREAgent / $SysReset 等
  Edge 旧版本残留                  升级后遗留的旧版本目录
  WebView2 旧运行时                旧运行时（默认不勾选）
  夸克旧版本残留                   只删废弃版本
  WPS 缓存与旧版本                 旧版本 + 插件重复副本 + 缓存日志
  WinSxS 组件清理                  DISM 官方组件回收，10~30 分钟

扫描永远是只读的。清理前会弹窗列出将删除的内容与预计释放量，确认后才动手。


三、安全规则（这几条是踩过坑才写进去的）
----------------------------------------
1. Edge 的旧版本判定不看版本号高低。
   根目录的 msedge.exe 通过 SxS 清单硬绑定某个具体版本目录，删掉被绑定的版本会让
   Edge 永久无法启动。所以程序会先解析每个引导器的绑定版本，绑定的、正在运行的、
   目录内最高的，三者都保护。删完还会做一次健康检查，异常会在日志里直接告警。

2. WPS 的 office6\backup（自动备份）永不删除。
   里面是崩溃恢复副本，可能是唯一没存盘的版本。程序只在界面上显示它的大小。

3. 夸克的保留版本从四个来源交叉验证。
   Last Version 文件 / 注册表 / 根目录主程序 / 运行进程，任何一个来源都可能出错。

4. 2 小时内变动过的版本目录一律跳过。
   防止刚升级、还没完成切换的版本被误删。

5. 不杀进程。相关程序正在运行时，被占用的文件自动跳过，不会强制关闭你的软件。

6. 小米组件的「当前版本」按各自的真实归属判定，不统一按版本号最高。
     · MiService / XiaomiPCManager 有系统服务，读服务 ImagePath 指向哪个版本目录
     · AIService 没有服务，读注册表 DisplayVersion，并把目录内最高版本一并保护
     · 云更新器的安装包只处理 90 天以前的，避免删掉正在进行的更新
   服务信息读不到时，退回「保留最高版本」并在备注里标注，绝不按顺序盲删。


四、权限
--------
以普通权限运行也能用，但小米管家 / Edge / WebView2 / 夸克 / WinSxS / 更新缓存
这几项在 C:\Program Files 和 C:\Windows 下，需要管理员权限才能删除。

界面顶部有黄色提示条时，点「以管理员身份重启」即可（会弹 UAC 确认）。


五、这台机器的实测情况（2026-11-23 扫描）
-----------------------------------------
  MiService            22 个版本堆到 8.00 GB；已手动清理 21 个，收得 7.54 GB
  AIService            6 个版本 1.99 GB，当前 2.0.2.1，5 个旧版可清 1.55 GB
  XiaomiPCManager      5.8.1.140 运行中；5.8.1.130 是空壳残留 1.32 MB
  xiaomicloud-updater  2024 年的安装包 + 待安装包，共 177.8 MB

  合计还能回收约 1.73 GB（小米组件这一项）

  C 盘：清理前 19.45 GB 可用 → 手动清完 MiService 后 28.76 GB 可用（共 145.35 GB）
  注意 pagefile.sys 由系统自动管理（当时 9.79 GB），它的涨落会让可用空间来回波动，
  这不是清理没生效。

  同机其他可清项（原版模块已覆盖）：WPS、夸克、Edge、WinSxS、更新缓存。
  回收站当时仅 0.01 GB，无需处理。


六、文件说明
------------
  CleanCDrive.exe      成品，双击就用（PyInstaller 打包的单文件 exe）
  CleanCDrive.pyw      图形界面源码
  cleaner_core.py      清理引擎（所有判定与删除逻辑，可单独 --scan）
  CleanCDrive.spec     PyInstaller 打包配置，改完源码重新打包用得上：
                       python -m PyInstaller --noconfirm --clean CleanCDrive.spec
  app.ico              图标
  启动 C盘清理工具.cmd  从源码启动的入口（需要 Python）
  cleanup_log.txt      每次清理的记录（自动生成，exe 版在 %LOCALAPPDATA%\CleanCDrive\）


七、想先看看会删什么
--------------------
在本文件夹打开 PowerShell，执行：

    python cleaner_core.py --scan

只会打印清单，不删除任何东西。适合装完 Python 后先验证一遍。


八、界面在不同分辨率和缩放下的表现
----------------------------------
窗口尺寸不写死。程序先按系统 DPI 算出缩放系数（100% / 125% / 150% /
200% / 250% 分别对应 1.0 / 1.25 / 1.5 / 2.0 / 2.5），再把设计尺寸乘上去，
上限取屏幕的 94%，所以窗口不会超出屏幕。

列表每行按"实际字宽"排：启动时先量出最长模块名、最长描述的像素宽度，
据此确定各列宽度，并据此定出窗口最小宽度。文字会随缩放变大、像素常量
也同步放大，两者不会错位——旧版把名字框写死 170 像素，在 200% 缩放下
名字和描述就会叠在一起。

只有窗口被拖得比最小宽度还窄时，描述才会用省略号收尾，鼠标停在上面
会弹出完整文字。屏幕特别窄时，「DISM ResetBase（之后无法卸载更新）」
会自动缩成「DISM ResetBase」，避免被挤出窗口。
